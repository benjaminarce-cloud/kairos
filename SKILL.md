# Kairos Editorial Design Defaults

Use this skill guidance whenever designing or refining Kairos screens.

## Visual Posture

Kairos should feel like a calm editorial workspace for academic drafting, not a cheerful SaaS app. Favor restraint, depth through spacing, and deliberate hierarchy.

## Layout Rules

- Keep dashboards left-weighted and practical.
- Use asymmetry instead of centered hero stacks when possible.
- Let whitespace create rhythm before adding borders or decoration.
- Use cards only as quiet containers for real work objects.
- Keep mobile breathable with generous vertical spacing and clear CTAs.

## Interaction Tone

- Loading copy should be specific and editorial, such as "Reading the assignment brief" or "Composing a first pass".
- Never imply that work was submitted to Canvas.
- Drafting workflows should make review and intentional user action obvious.

## Color And Type

- Use `#0E0C0A` for the base background.
- Use `#1A1614` for quiet surfaces.
- Use `#2A2520` for borders.
- Use `#F5F1EA` for primary text and `#A39B8E` for muted text.
- Use `#3F5D4A` sparingly for state, focus, and primary actions.
- Use Cormorant Garamond for headings and Inter for body copy.
